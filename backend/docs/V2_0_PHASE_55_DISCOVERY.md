# V2.0 Phase 55 Discovery

## Objective
Evaluate the target train's ordered route occurrences as a set of distinct sequence vertices and calculate the strict mathematical density of the directed subgraph induced by the broader timetable network. This extracts a normalized metric reflecting how densely interlinked the train's sequence is via forward bypasses and backward return loops.

## Candidate
**Train Route Sequence-Induced Subgraph Density**

## Analytical Question
When mapping the global network's direct structural edges onto the specific combinatorial sequence space of a target train, what fraction of all logically possible forward non-adjacent sequence pairs and backward sequence pairs are actually realized?

## Endpoint
`GET /api/v1/network/trains/{train_number}/sequence-subgraph-density`

## Mathematical Definition
Let the train's route be defined as an ordered sequence of vertices $V = \{1, 2, \dots, n\}$ where each vertex $i$ is a sequence occurrence mapping to a physical station identity $S_i$.
Let $E_{global}$ be the set of all distinct directed topological edges $(U, V)$ generated by any train's adjacent consecutive stops in the active snapshot.

**Combinatorial Space (Possible Edges)**:
For $n$ occurrences, there are $n(n-1)$ possible directed pairs $(i, j)$ where $i \neq j$.
- **Forward Non-Adjacent Pairs**: $j > i + 1$. Maximum possible: $D_{fwd\_max} = \frac{(n-1)(n-2)}{2}$
- **Backward Pairs**: $j < i$. Maximum possible: $D_{bwd\_max} = \frac{n(n-1)}{2}$

**Realized Chords (Numerators)**:
- $F_{actual} = |\{ (i, j) \mid j > i + 1 \land (S_i, S_j) \in E_{global} \}|$
- $B_{actual} = |\{ (i, j) \mid j < i \land (S_i, S_j) \in E_{global} \}|$

**Normalized Density**:
- **Forward Density**: $D_{fwd} = F_{actual} / D_{fwd\_max}$ (0.0 if $n < 3$)
- **Backward Density**: $D_{bwd} = B_{actual} / D_{bwd\_max}$ (0.0 if $n < 2$)

## Exact SQL-Level Conceptual Logic
```sql
WITH target_seq AS (
    SELECT station_id, stop_sequence as seq
    FROM train_stop_observations
    WHERE train_id = :target_train_id AND snapshot_id = :snap_id
),
global_edges AS (
    SELECT DISTINCT s1.station_id as o, s2.station_id as d
    FROM train_stop_observations s1
    JOIN train_stop_observations s2 
      ON s1.train_id = s2.train_id AND s2.stop_sequence = s1.stop_sequence + 1
    WHERE s1.snapshot_id = :snap_id
)
SELECT 
    (SELECT COUNT(*) FROM target_seq) as n,
    COUNT(CASE WHEN ts2.seq > ts1.seq + 1 AND ge.o IS NOT NULL THEN 1 END) as fwd_actual,
    COUNT(CASE WHEN ts2.seq < ts1.seq AND ge.o IS NOT NULL THEN 1 END) as bwd_actual
FROM target_seq ts1
JOIN target_seq ts2 ON ts1.seq != ts2.seq
LEFT JOIN global_edges ge ON ge.o = ts1.station_id AND ge.d = ts2.station_id;
```

## Repeated/Cyclic Semantics
Vertices are strictly distinguished by their sequence index ($i$ and $j$). If a physical station is repeated (e.g., visited at index 1 and index 7), it forms two distinct chronological vertices. All sequence pairs $(1, 7)$, $(7, 1)$, $(6, 7)$, etc., are evaluated combinatorially. Pairs are excluded ONLY if their sequence index is identical ($i = j$) or consecutive ($j = i+1$), preserving full cyclic combinations without false invalidation based on identical station codes.

## Edge Cases
- **Undefined/Zero Cases**: If $n < 3$, $D_{fwd\_max}$ evaluates to 0, and `forward_density` forces a return of `0.0`. If $n < 2$, `backward_density` forces `0.0`.
- **Missing Train**: Returns standard 404.

## Distinction from Phase 38 (Topological Bypass Analytics)
Phase 38 operates on the **physical station pair space**. It collapses the train's route into distinct physical $(O, D)$ pairs and counts the absolute number of unique physical station-to-station shortcuts. Phase 55 operates on the **combinatorial sequence occurrence space**. It evaluates every $(i, j)$ sequence step explicitly, computes the rigorous mathematical density (fraction of realized combinatorial edges), explicitly handles cyclic repetitions dynamically (which Phase 38 physically collapses), and introduces the fully distinct backward (return loop) dimensional density ignored by Phase 38.

## Distinction from Other Nearby Phases
- **Phase 39 (Edge Traversal Dispersion)**: Evaluates temporal/train diversity on a single physical edge. Phase 55 evaluates topological density across a single train's entire sequence.
- **Phase 45 (Station Pair Route Diversity)**: Counts distinct paths between a single $(O, D)$ pair. Phase 55 evaluates 1-hop edge existences across all $(i, j)$ combinations simultaneously.
- **Phase 49 (Route Extension)**: Extends outward radially from a pair boundary. Phase 55 evaluates internal combinatorial density within the bounded sequence sequence.

## Snapshot-2 Validation Examples
- **12951 (Rajdhani)**: $n=202$. $D_{fwd\_max}=20,100$. $D_{bwd\_max}=20,301$. 
  - $F_{actual}=2 \implies D_{fwd} \approx 0.000099$
  - $B_{actual}=203 \implies D_{bwd} \approx 0.00999$
- **04853 (Passenger/Cyclic)**: $n=12$. $D_{fwd\_max}=55$. $D_{bwd\_max}=66$. 
  - $F_{actual}=13 \implies D_{fwd} \approx 0.236$ (23.6% sequence bypass coverage)
  - $B_{actual}=24 \implies D_{bwd} \approx 0.363$ (36.3% sequence return coverage)

## Performance Considerations
The `CROSS JOIN` (or `ts1.seq != ts2.seq`) evaluates $n(n-1)$ rows per train. The maximum observed $n \approx 500$, generating $\approx 250,000$ internal pairs, which easily executes entirely in memory within milliseconds. Hash Joining this localized combinatorial space against the pre-aggregated $\sim 20$K `global_edges` executes extremely efficiently in PostgreSQL (typically $<150$ms).

## Explicit Non-Claims
This metric makes NO claims about:
- Physical layout or track geometry.
- Geographic proximity.
- Real-time train delays or actual movement.
- Passenger viability (a sequence-induced backward loop does not imply a valid passenger transfer).
It strictly describes the density of the induced directed graph over the sequence occurrences.

## Acceptance Criteria
- Response schema correctly maps $n$, maximum theoretical denominators, actual numerators, and resulting float densities.
- Values exactly replicate Snapshot 2 combinatorial mathematics.
- All pairs correctly respect $i \neq j$ based solely on `stop_sequence`.
